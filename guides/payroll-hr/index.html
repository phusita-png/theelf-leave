1
❶ สร้างทะเบียนเดือนใหม่ ถ้ายังไม่มี tab
ก๊อปโครงจากเดือนก่อน + ระบบทำให้อัตโนมัติ: ดึงฐานเงินเดือนจาก OT · เพิ่มพนักงานใหม่ · คิด pro-rate คนเข้า–ออก/ลาออกให้เอง
ระบบเด้งสรุป "เพิ่มใคร / ฐานเปลี่ยนใคร / ใครลาออก" — อ่านทวนก่อนทำต่อ
2
❷ ดึง OT จากระบบ OT ต้องทำ
ดึงยอด OT ที่คำนวณไว้เข้าทะเบียน (col J) — ระบบรายงานคนที่ "จับคู่ชื่อไม่เจอ" ให้ → แก้ชื่อให้ตรง 2 ไฟล์
3
💸 ดึงวันลาไม่รับเงิน + 💵 คำนวณตามวัน ต้องทำทุกเดือน
เมนู 📂 Pro-rate → ดึงวันลาไม่รับเงิน (เข้า col AI) แล้วคำนวณเงินเดือนตามวัน (หัก col I)
* ครั้งแรกของไฟล์ใหม่ ต้องกด "⚙️ เพิ่มคอลัมน์ pro-rate" ก่อน 1 ครั้ง
4
❸ อัปเดต YTD สะสม ทำหลัง OT+ลานิ่ง
คิด ภาษี + ยอดสะสมทั้งปี — ต้องทำหลังเงินเดือน/OT/ลา นิ่งหมดแล้ว
5
❹ สร้างสลิป PDF (ตรวจก่อนส่ง)
สร้างไฟล์สลิปไว้ตรวจ — เปิดดู 3–5 คน เช็ก ชื่อ / เงินเดือน / ภาษี / สุทธิ / หมายเหตุลา ให้ถูกก่อนส่งจริง
6
❺ ส่ง Email + LINE
ส่งสลิปจริงให้พนักงานทุกคน — ขั้นสุดท้าย (สถานะขึ้น "✅ ส่งแล้ว")
🔁
แก้อะไรหลังกด ❸ YTD แล้ว ต้องกด ❸ ใหม่! เช่น เผลอดึง OT ใหม่ / แก้เงินเดือน หลัง YTD → ภาษีกับยอดสะสมเพี้ยน ต้องกด ❸ ซ้ำ (และเดือนถัด ๆ ไป เพราะ YTD สะสมต่อเนื่อง)
3 จัดการพนักงาน
เพิ่มใหม่ · ลาออก · ปรับฐานเงินเดือน — แก้ที่ "ต้นทาง" แล้วระบบดึงเอง
กรณีทำที่ไหน / ยังไง
➕ พนักงานเข้าใหม่เพิ่มแถวในชีต "พนักงาน" (ไฟล์ Payroll) ให้ครบ · ตอนกด ❶ สร้างเดือนใหม่ ระบบจะเพิ่มเข้าทะเบียนให้เอง
👋 พนักงานลาออกชีต "พนักงาน" → ใส่สถานะ "ลาออก" + วันลาออก (col P) · ระบบคิด pro-rate วันสุดท้าย + เดือนถัดไปเงินเดือน = 0 (ลบแถวทีหลังได้)
💵 ปรับฐานเงินเดือน (ถาวร)แก้ที่ ไฟล์ OT ▸ ชีต "อัตราค่าจ้าง" ช่องเงินเดือน → payroll ดึงฐานใหม่ตอนสร้างเดือนถัดไป
📈 ปรับฐานกลางรอบที่ OT "อัตราค่าจ้าง" ใส่ "วันปรับฐาน" + "ฐานใหม่" เฉพาะคนที่ปรับ → payroll คิดครึ่งรอบให้
⚠️
ชื่อ–สกุลต้องสะกดตรงกันทั้งไฟล์ OT และ Payroll — ระบบจับคู่ฐานเงินเดือน/OT ด้วยชื่อ · ถ้าสะกดต่าง คนนั้นจะใช้อัตราเก่าใน payroll แทน (ไม่ได้ฐานใหม่จาก OT)
🔐
มีพนักงานเข้าใหม่/เปลี่ยน LINE → เมนู 📂 พนักงาน/ทะเบียน มีเครื่องมือ: ดึงเลขบัตร · ดึง LineUserID · ตรวจการผูก LINE↔พนักงาน (กันสลิปหลุดข้ามคน)
4 Pro-rate — เงินเดือนไม่เต็มเดือน
เมนู 💰 Payroll ▸ 📂 Pro-rate
➗
หลักการคิด: เงินเดือน = ฐาน ÷ 30 × (จำนวนวันทำงาน − วันลาไม่รับเงิน) · ตัวหาร 30 ตายตัว (ตามกฎหมายแรงงาน)
เคสทำยังไง
วันลาไม่รับเงินกด 💸 ดึงวันลาไม่รับเงิน (ดึงจากระบบลา → col AI) แล้ว 💵 คำนวณตามวัน — ทำทุกเดือน
เข้า–ออกกลางเดือนใส่วันเริ่มงาน/วันลาออกในชีตพนักงาน → ระบบคิด pro-rate ให้ตอนสร้างเดือน
ปรับฐานกลางรอบวิธีถาวร = ใส่ที่ OT (วันปรับฐาน+ฐานใหม่) · วิธีเฉพาะเดือนนี้ = wizard "ปรับฐานกลางรอบ"
📝
wizard ปรับฐานกลางรอบ = แก้ เฉพาะเดือนนี้ (col I + note) · ถ้าจะให้ถาวร/เดือนถัดไปถูก → ต้องแก้ที่ OT "อัตราค่าจ้าง" ด้วย
5 เข้าใจภาษีหัก ณ ที่จ่าย
ทำไมเพิ่มรายได้แล้วภาษีไม่ขยับ — อ่านอันนี้
ระบบคิดภาษีแบบ "คิดทั้งปี แล้วหาร 12" (วิธีหัก ณ ที่จ่ายมาตรฐานสรรพากร):
(เงินเดือน+OT+incentive+ตกเบิก)×12 −ค่าใช้จ่าย 50% (≤100,000) −ลดหย่อนส่วนตัว 60,000 −ประกันสังคมทั้งปี =เงินได้สุทธิ → ขั้นบันได ÷ 12
💡
ขั้นแรก 0–150,000 = ไม่เสียภาษี (0%)
→ พนักงานเงินเดือนหลักหมื่นต้น ๆ ภาษี = 0 เป็นเรื่องปกติ (เงินได้สุทธิทั้งปียังไม่ถึง 150,000)
→ เพิ่ม OT/incentive นิดหน่อยภาษีก็ยัง 0 จนกว่าสุทธิจะทะลุ 150,000 (เงินเดือนราว ๆ เกิน 26,000/เดือนถึงเริ่มเสีย)
🔎
คนเงินเดือนสูงแต่ภาษีขึ้น 0 — เช็ก col N ในชีตพนักงาน!
ระบบคิดภาษีเฉพาะคนที่ col N "หักภาษี ณ ที่จ่าย" = "ใช่" · ถ้าไม่ใช่ "ใช่" → ภาษี = 0 ไม่ว่าเงินเดือนเท่าไหร่
ตั้งใจ (เช่น กรรมการยื่นภาษีเอง) = OK · ถ้าลืม → แก้ col N = "ใช่"
🧾
ตกเบิก (col O) = เงินเดือนย้อนหลัง → คิดภาษีด้วย (รวมในฐานภาษีแล้ว) · แต่ถ้าตกเบิกเป็น เบิกคืนเงินสำรองจ่าย (ไม่ใช่เงินได้) อย่าใส่ใน col O นี้
6 เก็บตกข้ามเดือน
จ่ายเงินไปแล้ว เพิ่งเจอที่ตกหล่น — ทำยังไง
💸
จ่าย/โอนเงินไปแล้ว = แก้ตัวเลขเดือนเก่าย้อนหลังไม่ได้
ถ้าเพิ่งเจอว่าหักน้อยไป (เช่นลืมหักวันลาไม่รับเงิน) → ห้ามแก้เดือนเก่า (ระบบจะไม่ตรงกับเงินจริง + สลิป/ภาษีที่ยื่นไปแล้ว)
→ ให้ หักคืนในเดือนถัดไป ที่ col U (หักอื่น ๆ) + ใส่ note เหตุผล (เช่น "หักคืนลาไม่รับค่าจ้าง 18/05 ตกหล่นเดือน 5")
→ ใช้อัตราของเดือนที่ลาจริง (ฐานเดือนนั้น ÷ 30 × จำนวนวัน) แล้วกด ❸ อัปเดต YTD ใหม่
7 สลิปเงินเดือน
สร้าง → ตรวจ → ส่ง · เมนู 💰 Payroll ❹/❺
1
❹ สร้างสลิป PDF
ระบบสร้าง PDF รายคนเก็บใน Drive + ใส่ลิงก์ในทะเบียน (สถานะ "📄 สร้างแล้ว" สีเหลือง)
2
🔍 ตรวจก่อนส่ง
เปิดลิงก์สลิป 3–5 คน → เช็ก ชื่อ / เงินเดือน / OT / ภาษี / SSO / หมายเหตุลา · สลิปแสดงเงินเดือนเต็มก่อนหักลา + บรรทัด "ลาไม่รับค่าจ้าง" แยก
3
❺ ส่ง Email + LINE
แชร์ PDF + ส่ง Email + LINE Flex ให้พนักงาน (สถานะ "✅ ส่งแล้ว" สีเขียว)
🛡️
กันสลิปหลุดข้ามคน: ก่อนส่ง ถ้ามีพนักงานเข้าใหม่/เปลี่ยน LINE → รัน 📂 พนักงาน ▸ ตรวจการผูก LINE↔พนักงาน ก่อน · ถ้า PDF ออกผิดคนหลังส่ง → ดูหัวข้อ "ฉุกเฉิน" ทันที
8 งานสิ้นปี (ทำปีละครั้ง)
เมนู 💰 Payroll ▸ 📂 รายงานสิ้นปี
งานทำอะไร
📦 ส่งออกทะเบียนจ่ายออกไฟล์ Excel ทะเบียนจ่ายทั้งปี (3 sheets)
📊 สร้าง ภ.ง.ด.1กสรุปภาษีหัก ณ ที่จ่ายรายปี ยื่นสรรพากร
✅
ก่อนทำสิ้นปี เช็กว่า เลขบัตรประชาชน (col O ในชีตพนักงาน) ครบทุกคน + YTD รันครบ 12 เดือน — ไม่งั้น ภงด.1ก/SSO จะไม่ครบ
9 แก้ปัญหา + ฉุกเฉิน
เจออาการไหน เทียบตารางนี้ได้เลย
อาการสาเหตุ / วิธีแก้
ดึง OT แล้วได้ 0 / ไม่พบชีท OTยังไม่ได้ คำนวณ OT ในไฟล์ OT → กลับไปคำนวณก่อน
OT/ฐาน ดึงเข้าไม่ครบบางคนชื่อสะกดไม่ตรง 2 ไฟล์ → ดูชื่อที่ระบบรายงาน "หาคนไม่เจอ" แล้วแก้ให้ตรง
ฐานเงินเดือนเดือนใหม่ไม่อัปเดตแก้ฐานที่ OT "อัตราค่าจ้าง" (ไม่ใช่ในชีต payroll) แล้วสร้างเดือนใหม่
คนลาไม่รับเงินแต่ไม่ถูกหักลืมกด 💸 ดึงวันลาไม่รับเงิน · หรือใบลาตกรอบอื่น (ยึดวันเริ่มลา) · จ่ายแล้ว → "เก็บตกข้ามเดือน"
เงินเดือนสูงแต่ภาษี = 0เช็ก col N "หักภาษี" = "ใช่" · หรือเงินได้สุทธิยังไม่ถึง 150,000 (ดูหัวข้อภาษี)
ภาษี/สุทธิเพี้ยน หลังแก้ตัวเลขแก้อะไรหลัง YTD → ต้องกด ❸ อัปเดต YTD ใหม่ (และเดือนถัด ๆ ไป)
ลงข้อมูลผิดเดือนคลิก tab เดือนผิด → คลิก tab เดือนที่ถูกก่อนกดเมนูเสมอ (กฎทองข้อ 1)
วันที่กลายเป็นปี 19xxกรอกปีไม่ครบ (เช่น 5/5/69) → พิมพ์เต็ม 5/5/2569 · วันที่เพี้ยนทำคิดรอบผิด
🚨
ฉุกเฉิน — สลิป PDF เนื้อหาผิดคน (privacy breach)
1. หยุดทันที อย่ากด ❺ ส่งอีก
2. แจ้งทีมพัฒนาระบบให้ ลบสิทธิ์เข้าถึง PDF ทุกไฟล์เดือนนั้น + ลบไฟล์ใน Drive
3. แจ้งพนักงาน + ขอโทษ · 4. แก้ต้นเหตุ (มักเป็นการผูก LINE ผิด) → สร้าง+ส่งใหม่
