1
คำนวณ OT รอบเดือน (26-25) ต้องทำ
ระบบสร้างชีต การคำนวณ OT MM-YYYY (ปี ค.ศ.) — นี่คือชีตที่ Payroll จะมาดึงต่อ
2
สร้างเอกสาร + ส่งสรุป OT ทาง LINE ทำเมื่อต้องการ
📄 สร้างเอกสารใบสรุป OT รายคน → 💬 ส่งสรุป OT ทาง LINE — ไม่กระทบ payroll จะทำตอนนี้หรือทีหลังก็ได้
⚠️
ถ้าชื่อพนักงานสะกดไม่ตรงกันระหว่างไฟล์ OT กับ Payroll → ตอนดึง OT ระบบจะรายงาน "หาคนไม่เจอ" ให้ → แก้ชื่อให้ตรงทั้ง 2 ไฟล์
2 ขั้นที่ 2 — ไฟล์ Payroll
เปิดไฟล์ Payroll · เมนูชื่อ "💰 Payroll" — ทำเรียงลงมาตามนี้
🖱️
ก่อนเริ่ม: คลิก tab ทะเบียนเดือนที่จะทำให้ขึ้นค้างไว้ (กฎทองข้อ 1)
1
❶ สร้าง Sheet เดือนใหม่ ถ้ายังไม่มี
ก๊อปโครงจากเดือนก่อน + ระบบทำให้อัตโนมัติ:
• ดึงฐานเงินเดือนจากไฟล์ OT ชีต "อัตราค่าจ้าง" (ฐาน / วันปรับฐาน / ฐานใหม่)
• เพิ่มพนักงานเข้าใหม่ จากชีตพนักงานให้เอง
• คิด pro-rate คนเข้า–ออกกลางเดือน + คนลาออก (เงินเดือน = 0) ให้เอง
ระบบจะเด้งสรุปว่า "เพิ่มใคร / ฐานเปลี่ยนใคร / ใครลาออก" — อ่านทวนก่อนทำต่อ
🔗
ปรับฐานเงินเดือน · พนักงานใหม่–ลาออก แก้ที่ไหน? (แก้ที่เดียว ไม่กรอกซ้ำ)
• ฐานเงินเดือน + ปรับฐานกลางรอบ → แก้ที่ ไฟล์ OT ▸ ชีต "อัตราค่าจ้าง" ที่เดียว (เงินเดือน / วันปรับฐาน / ฐานใหม่) → payroll ดึงมาคิดเองตอนสร้างเดือน
• พนักงานเข้าใหม่ → เพิ่มในชีต "พนักงาน" (ไฟล์ Payroll)
• ลาออก → ใส่สถานะ "ลาออก" + วันลาออก (col P) ในชีตพนักงาน → ระบบคิด pro-rate ให้
2
❷ ดึง OT จากระบบ OT ต้องทำ
ดึงยอด OT ที่คำนวณไว้ในขั้นที่ 1 เข้าทะเบียน (col J) — ระบบถามยืนยัน + รายงานคนที่จับคู่ไม่ได้
3
📂 Pro-rate ▸ ดึงวันลาไม่รับเงินจากระบบลา ต้องทำทุกเดือน
ดึงวันลาเกินสิทธิ์ / ลาไม่รับเงินจากระบบลามาเข้า col AI (ใช้หักเงิน)
* ครั้งแรกของไฟล์ ต้องกด "⚙️ เพิ่มคอลัมน์ pro-rate" ก่อน 1 ครั้ง
⚠️
กดทุกเดือน "ก่อนจ่าย" เสมอ — แม้คิดว่าไม่มีใครลา
เคยเกิดจริง: ลืมกดขั้นนี้ก่อนจ่าย → พนักงานที่ลาไม่รับค่าจ้างไม่ถูกหักเงิน → จ่ายเกินไปแล้ว ต้องตามเก็บคืนทีหลัง (ดูหัวข้อ "เก็บตกข้ามเดือน")
หลังดึงเสร็จ ลองดู col AI ว่ามีใครขึ้นตัวเลขบ้าง
4
📂 Pro-rate ▸ คำนวณเงินเดือนตามวัน / ปรับฐานกลางรอบ เฉพาะมีเคส
ทำเฉพาะถ้ามี: คนเข้า–ออกกลางเดือน · ลาไม่รับเงิน · ปรับเงินเดือนกลางรอบ (มี wizard ให้)
5
❸ อัปเดต YTD สะสม ทำหลังสุด
ทำ หลัง OT + ลา + เงินเดือน นิ่งหมดแล้ว — ขั้นนี้คิดภาษี + ยอดสะสมทั้งปี
6
❹ สร้างสลิป PDF (ตรวจก่อนส่ง)
สร้างไฟล์สลิปไว้ตรวจ — เช็ก col J (OT) · col T (ภาษี) · col Z (สุทธิ) ให้ถูกก่อนส่งจริง
7
❺ ส่ง Email + LINE
ส่งสลิปจริงให้พนักงานทุกคน (Email + LINE) — ขั้นสุดท้าย
🔁
แก้อะไรหลังกด ❸ YTD แล้ว ต้องกด ❸ ใหม่! — เช่น เผลอดึง OT ใหม่ / แก้เงินเดือน หลังกด YTD ไปแล้ว → ภาษีกับยอดสะสมจะเพี้ยน ต้องกด ❸ อัปเดต YTD ซ้ำ (และเดือนถัด ๆ ไปด้วย เพราะ YTD สะสมต่อเนื่อง)
฿ เข้าใจภาษีหัก ณ ที่จ่าย
ทำไมเพิ่มรายได้แล้วภาษีไม่ขยับ — อ่านอันนี้
ระบบคิดภาษีแบบ "คิดทั้งปี แล้วหาร 12" (วิธีหัก ณ ที่จ่ายมาตรฐานสรรพากร):
(เงินเดือน+OT+incentive+ตกเบิก)×12 −ค่าใช้จ่าย 50% (≤100,000) −ลดหย่อนส่วนตัว 60,000 −ประกันสังคมทั้งปี =เงินได้สุทธิ → ขั้นบันได ÷ 12
💡
ขั้นแรก 0–150,000 = ไม่เสียภาษี (0%)
→ พนักงานเงินเดือนหลักหมื่นต้น ๆ ภาษี = 0 เป็นเรื่องปกติ (เงินได้สุทธิทั้งปียังไม่ถึง 150,000)
→ เพิ่ม OT/incentive นิดหน่อยภาษีก็ยัง 0 จนกว่าสุทธิจะทะลุ 150,000 (เงินเดือนราว ๆ เกิน 26,000/เดือนถึงเริ่มเสีย)
🔎
คนเงินเดือนสูงแต่ภาษีขึ้น 0 — เช็ก col N ในชีตพนักงาน!
ระบบคิดภาษีเฉพาะคนที่ col N "หักภาษี ณ ที่จ่าย" = "ใช่" เท่านั้น · ถ้าไม่ใช่ "ใช่" → ภาษี = 0 ไม่ว่าเงินเดือนเท่าไหร่
ถ้าตั้งใจ (เช่น กรรมการยื่นภาษีเอง) = OK · ถ้าลืม → แก้ col N = "ใช่"
🧾
ตกเบิก (col O) = เงินเดือนย้อนหลัง → ต้องคิดภาษีด้วย
สูตร col T รวมตกเบิกในฐานภาษีแล้ว · แต่ถ้าตกเบิกเป็นการเบิกคืนเงินสำรองจ่าย (ไม่ใช่เงินได้) อย่าใส่ใน col O นี้
↻ เก็บตกข้ามเดือน
จ่ายเงินไปแล้ว เพิ่งเจอที่ตกหล่น — ทำยังไง
💸
จ่าย/โอนเงินไปแล้ว = แก้ตัวเลขเดือนเก่าย้อนหลังไม่ได้
ถ้าเพิ่งเจอว่าหักน้อยไป (เช่นลืมหักวันลาไม่รับเงิน) → ห้ามแก้เดือนเก่า (ระบบจะไม่ตรงกับเงินจริง + สลิป/ภาษีที่ยื่นไปแล้ว)
→ ให้ หักคืนในเดือนถัดไป ที่ col U (หักอื่น ๆ) + ใส่ note เหตุผล (เช่น "หักคืนลาไม่รับค่าจ้าง 18/05 ตกหล่นเดือน 5")
→ ใช้อัตราของเดือนที่ลาจริง (ฐานเดือนนั้น ÷ 30 × จำนวนวัน) แล้วกด ❸ อัปเดต YTD ใหม่
≡ ตารางลำดับฉบับย่อ
ปรินต์แปะไว้ข้างจอ เปิดดูทุกเดือน
